# Documentation Update & Defense Deck Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce `docs/updated.docx` (manuscript updated and restructured) and `docs/presentation.pptx` (defense deck) from the existing files, with real screenshots and diagrams.

**Architecture:** Repeatable scripts in `docs/tools/`: a Node CDP script drives headless Brave for screenshots/diagram PNGs; Python (python-docx, python-pptx) builds the outputs; PowerShell + Office COM renders them for inspection. Checks are scripted assertions plus visual inspection of rendered pages.

**Tech Stack:** Node 24 (built-in WebSocket), Brave headless, Python 3 + python-docx 1.2 + python-pptx, PowerShell + Word/PowerPoint COM.

**Spec:** `docs/superpowers/specs/2026-10-08-documentation-and-deck-design.md`

## Global Constraints

- Never modify `docs/current.docx`, `docs/base_docu.docx`, `docs/ppt_template.pptx`.
- Outputs: `docs/updated.docx`, `docs/presentation.pptx`, `docs/assets/*.png`, `docs/diagrams/use-case.drawio`, `docs/diagrams/content-diagram.drawio`.
- New manuscript paragraphs reuse `current.docx` styles (`HeadingCustom`, `BodyTextCustom`, `Normal`); placeholders and passages to verify are highlighted yellow.
- Screenshots use only DemoSeeder data, on a throwaway SQLite DB in the scratchpad, `CSP_MODE=off`, port 8001.
- Facts come from the code: versions from `composer.lock`/`package.json`, test count from `php artisan test`.

## Review Focus

- Leftover outdated terms ("utility", "meter", "staff", "late fee") anywhere in `updated.docx` (Task 7 `check_docx.py` asserts zero, case-insensitive, outside References).
- A figure inserted wider than the page margins (Task 7: every inline image width ≤ section text width).
- Deck text overflowing its box at 18 pt+ (Task 7: visual check of every exported slide PNG).
- Screenshot captured before Livewire finished rendering (blank tables/spinners) (Task 1: wait for network idle + 800 ms; visual check of each PNG).
- Table of contents / figure numbering stale after edits (Task 7: Word COM `TablesOfContents.Update()` + figure caption sequence check).
