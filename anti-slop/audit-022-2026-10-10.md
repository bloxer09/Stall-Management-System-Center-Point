# Phone format validation

Scope: add phone-number validation to profile, registration, stall applications, and support settings. Existing form styling supplies the direction. ENERGY 1 / RHYTHM 1 / MOTION 1.

## Requested finding resolved

1. R-27 / R-32 PASS: phone fields previously accepted arbitrary strings. A shared server rule now validates Philippine mobile-number format. It accepts ten national digits starting with 9, domestic `09` format, and `639` or `+639` international format. Incorrect lengths, letters, symbols, other country codes, and duplicated prefixes fail validation. The shared input also has a browser pattern and visible, accessible format guidance.

Profile and support phone fields remain optional. Profile phone remains required while two-factor authentication is enabled. Registration and application phone fields remain required. Existing duplicate-number checks are retained. Invalid submissions preserve the saved number and do not create accounts or applications. This change validates format; it does not add an SMS delivery or ownership check.
