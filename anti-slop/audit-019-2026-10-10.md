# OTP expiry countdown verification

Scope: the requested countdowns for password reset, sign-in two-factor verification, and two-factor enrollment. Existing app typography, theme colors, dialogs, and button styling provide the design direction. ENERGY 1 / RHYTHM 1 / MOTION 1; numerical changes communicate remaining time without decorative motion.

The shared Blade component reads expiry from the password-reset session or the stored two-factor code. One JavaScript ticker updates all current timer elements through Livewire morphs and navigation. Weak references release removed elements. Validation and rejected resend attempts retain the deadline. Successful resends use the newly stored deadline. The client does not poll or submit on expiry; the server still validates codes. Password-reset verification now rejects a code at the exact expiry boundary.

Browser testing found that a per-component Alpine interval could stop after a Livewire morph. The final shared ticker resolves that failure. The timer uses `role="timer"` with live announcements off; a separate status announces expiry. Password reset offers a keyboard-accessible request-new-code button.
